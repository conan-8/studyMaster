# Boundaries

**Slug:** `boundaries` · **Domain:** Standard English Conventions

## What it tests

Whether the student can punctuate a sentence correctly at its structural
boundaries: between independent clauses, around parentheticals and
appositives, after introductory elements, and within lists. This is the
comma / semicolon / colon / dash / period item — pure convention, tested
with a fixed stem.

## Worked shape

One or two sentences of expository prose with a blank at a syntactic
boundary. The stem is always *"Which choice completes the text so that it
conforms to the conventions of Standard English?"* The four choices are
variants of the same words differing only in punctuation or connector.
Exactly one yields a complete, conventionally punctuated sentence; each
distractor commits one identifiable error (comma splice, semicolon before a
fragment, unclosed paired comma, subject–verb split).

## Original example item (medium difficulty)

> The conservation team expected the wetlands survey to take six weeks
> ______ unusually heavy spring rains, however, flooded the survey sites
> and stretched the project to eleven.

**Which choice completes the text so that it conforms to the conventions of
Standard English?**

- A) weeks,
- B) weeks;
- C) weeks
- D) weeks, and

**Why the distractors fail:** A creates a comma splice — "however" is a
conjunctive adverb, not a coordinating conjunction, so a comma alone cannot
join the two independent clauses. C leaves the clauses fused with no
punctuation at all. D uses a coordinating conjunction, which is a legal
joiner, but "and however" garbles the contrast logic and still mishandles
the conjunctive adverb's required punctuation. Only the semicolon (B)
correctly joins two independent clauses with "however."

## Difficulty commentary

- **Easy:** one clear boundary (two short independent clauses, or an obvious
  introductory phrase); distractors produce unmistakable run-ons.
- **Medium:** intervening phrases hide clause boundaries; semicolon vs comma
  with conjunctive adverbs; appositives needing paired commas.
- **Hard:** long sentences with embedded clauses where the test-taker must
  parse which elements are truly independent; restrictive vs nonrestrictive
  distinctions deciding whether commas belong; colon/dash items where the
  preceding clause must be independent.

## Generation pitfalls

1. **Testing style, not convention.** If two punctuations are both
   defensible (e.g. optional serial comma), the item is invalid. Test only
   settled rules.
2. **Word changes as a side channel.** Choices should differ only in
   punctuation/connector. If wording also varies, students can answer on
   style instead of structure.
3. **Ambiguous clause typing.** You must be able to parse the sentence
   yourself and state objectively which elements are independent. If the
   parse is genuinely contestable, rewrite.
4. **Distractors with two errors.** Each wrong choice should commit exactly
   one clean error — otherwise students can arrive at the key by elimination
   of the "most broken" options without knowing the rule.
5. **Missing the pair-check.** For parenthetical/appositive items, verify
   both the opening and closing marks of the pair in the full sentence.
