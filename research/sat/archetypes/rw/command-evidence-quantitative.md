# Command of Evidence: Quantitative

**Slug:** `command-evidence-quantitative` · **Domain:** Information and Ideas

## What it tests

Whether the student can read a small table or graph and select the statement
that *accurately uses the data* to support (or weaken) a claim in the
accompanying passage. Two filters must both be passed: the numbers must be
faithful to the table, and the comparison must be the one the claim actually
needs.

## Worked shape

A 1–3 sentence passage presents a hypothesis or conclusion, often ending in
a blank. Beside it sits a compact table — typically 3–6 rows by 2–4 columns
with clear headers and units. The stem is *"Which choice most effectively
uses data from the table to support [the] hypothesis?"* (or "to complete the
statement"). All four choices cite table data; exactly one is both
numerically accurate and logically relevant to the claim.

## Original example item (medium difficulty)

> A city planner claimed that converting two downtown traffic lanes to bus-only
> lanes in 2021 improved bus reliability without reducing overall corridor
> ridership.

**Average weekday corridor figures, 2019–2023**

| Year | Bus on-time rate (%) | Daily corridor trips (all vehicles, thousands) |
|------|----------------------|------------------------------------------------|
| 2019 | 61                   | 88                                             |
| 2020 | 64                   | 52                                             |
| 2021 | 74                   | 70                                             |
| 2022 | 79                   | 84                                             |
| 2023 | 81                   | 91                                             |

**Which choice most effectively uses data from the table to support the
planner's claim?**

- A) Daily corridor trips fell to 52,000 in 2020 before recovering in later
  years.
- B) Between 2019 and 2023 the bus on-time rate rose from 61% to 81%, while
  daily corridor trips ended the period higher, at 91,000 versus 88,000. ✔
- C) The bus on-time rate increased every year from 2019 through 2023.
- D) In 2023, the on-time rate was 81% and daily corridor trips totaled
  91,000.

**Why the distractors fail:** A is accurate but speaks to neither half of
the claim (it describes a pandemic dip). C is accurate about reliability but
ignores ridership, so it supports only half the claim. D cites accurate
single-year values but makes no comparison, so it demonstrates nothing.

## Difficulty commentary

- **Easy:** one decisive row; the claim points straight at one comparison;
  distractor misreads are gross.
- **Medium:** the supporting evidence requires 2–3 cells; one distractor is
  accurate-but-irrelevant; the claim has a qualifier the data must match.
- **Hard:** the key requires comparing *changes* (deltas/ratios); several
  choices cite real values that nearly fit; units/percentages or
  subgroup-vs-total traps are live.

## Generation pitfalls

1. **Unintended support.** Scan the table for accidental comparisons that
   also back the claim — if a distractor's numbers can be defended as
   supporting, the item is ambiguous.
2. **Arithmetic drift.** Every number quoted in every choice must be checked
   against the table cell by cell, including derived values (differences,
   percentages).
3. **Unlabeled units.** If the unit/percent trap is not intended, make units
   unmistakable; if it is intended, make it the *only* flaw of that
   distractor.
4. **Claims the table cannot address.** The claim must be about what the
   table measures — no causation claims where the table shows only
   correlation unless the item is a weaken variant exploiting exactly that.
