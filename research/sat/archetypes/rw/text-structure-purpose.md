# Text Structure and Purpose

**Slug:** `text-structure-purpose` · **Domain:** Craft and Structure

## What it tests

Whether the student can describe what a sentence *does* (its rhetorical
function), what a whole text is *for* (main purpose), or how a text is
*built* (overall structure). The skill is meta-reading: stepping back from
content to name the rhetorical move.

## Worked shape

A 1–3 sentence passage with a deliberate architecture (claim + example,
view + qualification, problem + response). For the function variant, one
sentence is underlined and the stem asks *"Which choice best describes the
function of the underlined sentence in the text as a whole?"* Choices are
descriptions like "It provides an example that illustrates..." or "It
qualifies the claim that...". The correct choice matches both the content
and the *role*; the classic trap summarizes content while mislabeling role.

## Original example item (medium difficulty)

> Nineteenth-century lighthouse keepers kept meticulous daily logs, and
> historians long mined those logs for weather records. <u>Recently,
> however, researcher Amara Diallo showed that the logs' entries on passing
> ships are equally valuable, revealing trade routes that official customs
> records omitted.</u> Her work has prompted a broader reassessment of what
> counts as a historical source.

**Which choice best describes the function of the underlined sentence in the
text as a whole?**

- A) It presents a finding that expands on the use of the logs described
  earlier in the text. ✔
- B) It refutes the claim that historians found the logs useful.
- C) It explains how lighthouse keepers were trained to keep daily logs.
- D) It summarizes the reassessment mentioned in the final sentence.

**Why the distractors fail:** B overstates the move — Diallo's work adds to,
not refutes, the earlier use. C invents content not in the passage (and the
sentence does no such explaining). D attaches the sentence to the wrong
object — the reassessment is the *consequence* described in the last
sentence, not what the underlined sentence summarizes.

## Difficulty commentary

- **Easy:** transparent two-sentence architecture; the underlined sentence
  plays an obvious role; distractors describe absent moves.
- **Medium:** relational roles (qualifies, illustrates, pivots); distractors
  include the content-not-role trap and a role reversal.
- **Hard:** subtle roles (anticipates an objection, narrows a
  generalization); distractors differ only in the strength of the rhetorical
  verb ("refutes" vs "qualifies"); literary passages where function is read
  through tone.

## Generation pitfalls

1. **Verb miscalibration in the key.** If the passage "suggests" and the key
   says "demonstrates," the key is wrong. Match the verb to the move's
   actual strength.
2. **Architectures that fit twice.** If the passage can plausibly be read as
   either compare-contrast or problem-solution, the structure variant is
   broken. Build one shape, unambiguously.
3. **Underlining a sentence with no distinct role.** Every sentence needs a
   job, and the underlined one's job must be unique — if two sentences do
   the same work, "function of the underlined sentence" has a twin answer.
4. **Content-only choices all the way down.** If every choice just
   paraphrases content with no rhetorical verb, the item tests comprehension,
   not structure.
